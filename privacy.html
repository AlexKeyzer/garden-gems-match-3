Политика конфиденциальности RU

Игра «Три в Ряд: Садовые Сокровища» (далее — Игра). Оператор: индивидуальный разработчик (контакт для обращений: support@example.com — замените на актуальный адрес перед публикацией).

1. Какие данные обрабатываются

  • Технические данные игрового прогресса: номер уровня, звёзды, монеты, настройки, статистика матчей — хранятся локально в браузере (localStorage) и в облачном хранилище платформы (GamePush player storage или VK WebApp Storage), если игра запущена внутри платформы.
  • При запуске внутри ВКонтакте игра получает через VK Bridge только базовые данные сессии: язык интерфейса и признак видимости окна (пауза/продолжение). Имя, аватар, список друзей и иные данные профиля не запрашиваются.

2. Цели обработки

  • сохранение прогресса между сессиями и устройствами;
  • корректная пауза при сворачивании;
  • локализация интерфейса.

3. Передача третьим лицам

Данные не передаются третьим лицам. Реклама в версии для ВКонтакте показывается платформой ВКонтакте/AppsCentrum самостоятельно; Игра не передаёт ей персональные данные и не вызывает рекламные показы из своего кода.

4. Хранение и удаление

  • Локальные данные удаляются кнопкой «Настройки → Сбросить прогресс» или очисткой данных сайта браузера.
  • Облачное хранение ВКонтакте управляется настройками вашего аккаунта VK (раздел «Приложения»); GamePush — согласно политике GamePush.

5. Дети

Игра имеет возрастную маркировку 6+ и не собирает осознанно персональные данные детей вне механизмов платформ, имеющих родительский контроль.

6. Изменения

Актуальная редакция всегда доступна по этому адресу (страница игрового сайта).

Privacy Policy EN

The game "Garden Gems: Match 3" (the Game). Operator: individual developer (contact: support@example.com — replace before publishing).

1. Data we process

  • Game progress data (level, stars, coins, settings, match stats) stored locally in your browser and, when launched inside a platform, in that platform's cloud storage (GamePush player storage or VK WebApp Storage).
  • When launched inside VK, the Game receives via VK Bridge only basic session data: interface language and window visibility (pause/resume). Profile name, avatar, friends and other profile data are NOT requested.

2. Purposes

  • saving progress across sessions and devices;
  • correct pausing when the app is hidden;
  • interface localization.

3. Sharing

No data is shared with third parties. Ads in the VK version are shown by VK/AppsCentrum on their own; the Game sends them no personal data and triggers no ad calls from its code.

4. Storage & deletion

  • Local data is removed via "Settings → Reset progress" or by clearing site data.
  • VK cloud storage is managed in your VK account settings (Applications section); GamePush per GamePush policy.

5. Children

The Game is rated 6+ and does not knowingly collect children's personal data outside platform mechanisms with parental control.

6. Changes

The current version is always available at this address (a page of the game site).
